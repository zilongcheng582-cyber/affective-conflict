# Reproducibility boundary statement V1

The preserved data layer supports scientifically stable, versioned canonical starting artifacts for all four datasets. This statement concerns data and input preparation; it does not claim that all model outputs or scientific results were reproduced from raw data in this audit.

EmotionTalk official annotations and media support canonical multimodal alignment, five source-label conflict patterns, the fixed1500-item controlled panel and its14 candidate-sequence assignments. A prior independent CPU replay reproduced the entire historical panel byte-for-byte, including selection and candidates. The frozen media mapping, prompt and retained input-construction source specify4500 Phase1 unimodal input slots without model outcomes. The recommended raw-data preparation boundary is **official raw → canonical1500 controlled panel → Phase1 inputs**.

Later EmotionTalk populations intentionally depend on prior model outputs: Phase1 predictions determine Readable/DualReadable/TripleReadable eligibility; Phase2 outcomes populate Phase3 composition fields. These belong to the experimental execution DAG, not the raw-data preparation DAG. The relevant historical outputs and402-row Phase3 plan are preserved and hashed. The historical primary-plan writer remains unrecovered; deterministic reuse of that frozen plan is supported, but independent generation of the full plan from new/different model outcomes is not established. No fresh inference or readability/composition scoring was performed here.

MCR official raw SER records uniquely provide the explicit adversarial competitor label. All1000 source records, explicit mappings, duplicate dispositions and the909-item arbitration population were independently matched by prior outcome-blind producers. Thus **official raw → canonical909** is supported without a frozen mapping lookup. The remaining limitation is the controlled candidate-order assignment algorithm, not labels, evidence identity or909 membership. Recreating the exact historical four-arm model inputs requires the **versioned, hashed full V2 controlled manifest**, which binds candidate_sequence/candidate_sequence_id for909 samples and3636 arm records. No candidate schedule is reverse-engineered, newly assigned or treated as a non-scientific difference. This frozen input-assignment artifact is an explicit boundary dependency.

LISTEN retains its existing raw-to-source-aligned V4 exact input-identity result, and CA-MER retains its existing complete canonical/media/input lineage. Neither dataset was reopened or reconstructed in this audit. Ordinary model execution is needed for scientific outputs in all datasets; a lack of prior model-output eligibility gates is not a claim that inference is unnecessary.

For current publication/B3 reuse, canonical snapshots and the disclosed frozen derived/input artifacts uniquely determine the preserved scientific populations and input conditions. Therefore the **clean canonical data layer is ready**, and **B3 is not blocked by data reproducibility**. This limited finding does not authorize B3 execution or assess runtime, feature readiness, scientific analysis code or other experimental blockers. The unresolved upstream candidate-assignment producer and the missing EmotionTalk primary-plan writer remain disclosed provenance limitations; no historical source, raw data, model result or scientific population was modified.
