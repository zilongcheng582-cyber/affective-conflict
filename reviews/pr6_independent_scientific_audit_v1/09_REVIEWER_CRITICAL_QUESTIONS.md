# 09 外部审稿人视角

**1. 当前最强、可以发表的单一科学主张是什么？**

在一个固定的、对模型而言两种模态都“可读”的 AV 情绪冲突子集（146 个 item）上，对 Qwen2.5-Omni-7B 的无声视频施加强高斯模糊（相对 RECODE），使联合判断与视频源标签一致的比例下降 40.8 pp（CI −47.6 至 −33.9）。流失的选择中 90% 转向音频源标签。这一效应在两种呈现顺序、对话聚类、录制组聚类和精确随机化检验下都稳健，并且与 ERI1 中音频退化的方向一致。

**2. 有没有代码实现错误会直接改变该主张？**

没有发现。y_A/y_V 映射、顺序、候选序列、解析器、ITT 和统计都经过独立复算和合成测试（01、03）。尚未独立核验的只有原始媒体和 teacher-forcing 的逐 token 数值（私有）。

**3. 哪些推断属于因果干预效应？**

在固定 item 上，“模糊处理（相对 RECODE）→ 联合输出类别分布变化”是受控的条件内干预效应，E1 和 E2 主终点都是如此。这里的“因果”是指对**这个特定处理**、这个模型、这些 item 的效应，不是对“可靠性”这一抽象构念的效应。

**4. 哪些只是机制一致性解释？**

- “模型根据可靠性重新分配模态权重”
- “L1/L2/L3 是可靠性梯度”
- 顺序交互所暗示的“位置/近因效应”
- entropy 的增加

**5. 哪些完全不可识别？**

- 内部仲裁或权重机制
- 最优加权
- entropy 中介
- 音频与视频的对称性
- ERI1 效应的“损伤 vs 仲裁”算术分解
- 对其他模型或自然冲突分布的推广

**6. E1 的大效应是否由近乎不可读的极重度模糊驱动？**

是，且应明确写出。

- L2/L3 下 V_ONLY 有 141/146 和 142/146 回答 neutral，在 y_V ≠ neutral 的 69 个 item 上 L3 命中 0/69。
- 联合 SIDE_V 在 L2 已降到 16.1%，L3 为 13.7%，基本饱和。
- 唯一的分级水平是 L1（σ ≈ 5.6 模型像素）：V_ONLY 匹配 67.8%，联合 SIDE_V 降低 17.1 pp（精确 p 5e−7，在 V1 计划的 Holm 下仍显著）。

所以 L3 主效应应理解为“视觉情绪信息被基本移除后的选择”。L1 才提供“部分退化”的证据。

值得注意：在 L3，V_ONLY 对 y_V = neutral 的 item 回答 neutral 的比例为 96%，而联合判断中这些 item 的 SIDE_V（= neutral）却从 42.9% 降到 14.3%。也就是说，联合判断**没有**跟随单模态视频的“neutral 读数”，而是转向音频。这排除了“模糊 → neutral 输出偏置”可以单独解释联合效应的可能，但仍不能识别内部机制。

**7. CLEAN−RECODE 的联合边际结果相同，是否足以证明输入管线等价？**

不足以。边际结果相同不能证明输入相同。证据要看帧级：144/146 的模型帧张量逐位相同，2/146 有微小差异（F08），而且这 2 个 item 的 5 个 arm 输出也完全相同。对 E1 来说，RECODE 是逐位接近无操作的对照。

E2 的音频 RECODE **不是**中性对照：A_ONLY 从 100% 降到 89.8%（F03）。

**8. DualReadable 筛选后，可读性下降是否受基线天花板影响？**

是。

- V_ONLY 在 RECODE 下为 100%，这是筛选造成的，所以 L3−RECODE 的 −49.3 pp 包含“从被筛选出的上限下降”。
- 联合 SIDE_V 有地板效应：51/146 个 item 在 RECODE 下从不选 SIDE_V，最多只能下降 54.45 pp。
- E2 基线 99.1%，几乎没有上升空间。
- 这些都不影响效应方向，但影响幅度的可比性和外推。

**9. 同一个模型的三个实验能否称为跨模态可靠性机制证据？**

不能称为“机制证据”。它们是同一模型上的互补干预：ERI1 退化音频，E1 退化视频，E2 是一致样本对照。可以称为“同一模型内、对两种模态退化的方向一致的行为证据”。

**10. 值得再运行 GPU 吗？**

就 PR #6 要支持的有边界结论而言，**不需要**。现有证据已经足以支持“特定处理的行为效应”。主要缺口（F01–F05）都可以通过文档限定解决。

只有一种情况需要新实验：如果研究目标要求识别**分级可靠性**（而不是信息移除）下的响应曲线，才需要在 L1 附近及以下（σ ≈ 0.25–1% 短边）加密退化水平，并且最好同时有经校准的单模态可读性匹配。它能识别的量是：在单模态可读性尚未坍缩时，联合选择对可读性的斜率。这个量现有数据只能由 L1 这一个点提供。这是可选的研究扩展，不是合并前提。
