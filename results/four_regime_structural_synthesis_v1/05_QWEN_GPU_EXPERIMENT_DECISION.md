# 05 Qwen 是否还需要新的 GPU 实验

**唯一优先决策：`ONE_FINAL_QWEN_EXPERIMENT_REQUIRED`**

唯一首选实验：**CA-MER 受控协议里已规划但仓库中无输出的 `A_ONLY` 与 `V_ONLY` 两个臂，在冻结的 16 类源本地接口下运行，并按 B3 的候选对数得分方式取得完整 16 类概率向量（熵、margin、源标签概率）。**
其余候选全部列为 optional，不自动执行；本轮不创建任何正式 GPU manifest，不启动 GPU。

这个决定是 CPU 综合得出的"哪些问题现有数据回答不了"的结果，不是预设方向。**Step 0 先于一切**：核对私有归档 `audit/QWEN25_CAMER_CONTROLLED_V1`（以及 `audit/QWEN25_MCR_CONTROLLED_V3`）里是否已有这些臂的行级输出。如果存在且含概率向量，则该实验降为 CPU 任务，本决策随之变为 `QWEN_CAN_FREEZE_AND_MOVE_TO_NEXT_MODEL`；仅有解析后的标签而无概率向量时，熵特征仍不可得，GPU 仍需要。

---

## 为什么是它：证据缺口来自哪里

1. R1 是论文的第一核心发现（ET 内熵不对称→仲裁，AUROC≈0.80），ERI1 已把"音频质量→仲裁"的因果性在 ET 内封版。**两者现存的最大外部效度缺口是：这个关联在另一个自然 A–V 冲突数据集上是否成立。** 现有 CA-MER 回答是"几乎不成立"（未拟合规则 AUROC 0.51 / 0.57），但这些特征是在 7 类 B3 空间里测的，而 CA-MER 的冲突标签有 31.7%（音频侧）与 42.9%（视频侧）落在 7 类之外。
2. 本轮 CPU 分层显示这个缺口**不是纯 null**：两源标签都在 7 类内时 AUROC 升至 0.64 / 0.71，在 7 类外时是 0.49 / 0.52（`X3`）。这是一个现有数据**能生成但不能验证**的假说——验证需要在 16 类接口下测的熵。
3. CPU 数据不能回答：CA-MER 受控 A_ONLY/V_ONLY 输出不在仓库、`final_label` 被排除、B3 只有 7 类。
4. 同时它也是最便宜的：1500 个样本 × 2 个单模态臂 = 3000 次单模态前向（无采样、无联合臂），联合臂的行级结果（2884 个有效试次）已固定，可直接作为结局。

## 该实验要区分的竞争解释

| 解释 | 预测（16 类特征） |
|---|---|
| H1：熵不对称—仲裁是 ET 之外也成立的一般规律，CA-MER 的低 AUROC 是测量空间不兼容 | CA-MER 全集未拟合规则 AUROC 明显升高（接近 7 类内子集的 0.64–0.71 或更高） |
| H2：该关联依赖 ET 的人工逐模态标注/7 类体系，不推广到伪标签数据集 | AUROC 仍≈0.5 |
| H3：CA-MER 的选择主要跟随构造标记（audio-/video-aligned）所携带的、与熵无关的证据差异 | AUROC≈0.5，但 aligned 间的 P(音频\|二选一) 差异（0.74 vs 0.37）仍在；可进一步用 16 类 A_ONLY/V_ONLY 的"读对 y_A/y_V"来看构造间的单模态可读性差异 |
| H4：单模态读取不稳（与 ERI1 观察到的 ~10% RECODE 回归同类） | 可读性（A_ONLY 解析==y_A）在两臂内部低且不一致；是否稳需要重复，见下 |

## 最小独立样本与配对单位
- 独立单位：CA-MER 样本（1500，其中 1000 冲突、500 一致控制）；配对单位：同一样本的 A_ONLY 与 V_ONLY 以及两个联合顺序。
- 候选集与候选顺序：必须用联合试次**已有**的逐样本候选序（`controlled.jsonl` 的 `candidate_order`），不改接口。
- 精度参考（来自现有数据）：二选一 695/655 试次（379/364 样本）时 AUROC 的 95% 区间半宽约 ±0.065；合并两构造约 ±0.045。足以区分 0.50 与 ≥0.60，以及 0.57 与 ≥0.70。

## 必须预先冻结的控制（建议，供正式 protocol 采用；本轮未创建 manifest）
1. 结局固定为已有的 2884 个有效联合试次的 SIDE_A / SIDE_V / OTHER（不得重跑联合臂，116 个 OOM 保持缺失并报告）。
2. 主要估计量：未拟合规则 S16 = H16(V) − H16(A)（归一化熵用 ln16）预测二选一方向的簇 AUROC，样本为簇；顺序内 AUROC 作为稳健性。
3. 不重新拟合、也不直接套用 ET 冻结系数（其标准化基于 7 类，套用无定义）；任何数据集内拟合须另命名为探索性。
4. 判读规则（建议在看到数据前冻结，不由本报告的观察值反推）：合并 AUROC 的 95% CI 下界 ≥0.60 → 支持"关联超出 ET"；上界 ≤0.55 → 关联不超出 ET；其余 → 不下结论。
5. 稳定性控制：随机 20%（~300）样本的音频做一次 RECODE 式字节不同重编码，复测 A_ONLY，以量化"可读性"回归（ET 观察到 ~10%）。
6. 解析器、提示、解码设置与联合试次保持一致；技术失败与 PARSE_FAIL 完整记账，不丢弃。

## 零结果或反方向给出什么
- ≈0.5：R1 的适用范围应写成"EmotionTalk 的人工逐模态标注 + 7 类体系"；CA-MER 的迁移失败是实质性的，不再是测量问题。这是对论文范围的明确限定，价值同样高。
- <0.5：熵在 CA-MER 上可能反映对错误标签的自信，需要重审 R1 中"熵=证据强度"的措辞（目前已限定为模型内部特征）。
- 明显 >0.6：R1 获得跨数据集支持，可在第二模型里直接复用同一设计。

## 是否值得消耗 Qwen GPU；能否由第二模型承担
值得。成本是数千次单模态前向，而且这是 CA-MER 迁移叙事从 `MEASUREMENT_INCOMPATIBLE` 变成可解释结论所缺的最后一块。第二模型**不能**代替它：另一个模型的 16 类熵无法解释 Qwen 的联合选择；而第二模型的研究本来就需要运行同样的臂，且应以 Qwen 这一次结果作为参照。

## 何时可以停止 Qwen、转入第二模型
1. Step 0（归档核对，免费）完成；
2. 若需 GPU：完成唯一首选实验并做完 CPU 判读；
3. 此后 Qwen 冻结。预先写明的"重开"条件只有一条：第二模型的结果与 Qwen 在某个**预先命名的**对照上出现方向性分歧，且该对照在 Qwen 上从未运行（例如视频反向或 AV 一致对照）。其余情况不再消耗 Qwen GPU。
粗略估计：首选实验规模为一次 GPU 会话级别（约 3000 次单模态前向加少量稳定性重复），加上预注册与 CPU 判读，之后即可冻结 Qwen。
