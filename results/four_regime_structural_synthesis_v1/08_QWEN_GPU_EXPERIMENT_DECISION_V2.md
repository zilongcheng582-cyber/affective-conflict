# 08 修订版 Decision Report（取代 05 的结论）

全部新分析为 `POST_HOC_EXPLORATORY`。本轮只做 CPU 与只读检查，**不批准任何 GPU 运行**，不创建 GPU manifest，不重新冻结历史实验。
排序只按**科学识别价值**（能排除哪些替代解释、需要什么新数据、样本是否足以支持），不考虑论文吸引力或预期显著性。

## 最终决策
**`CPU_ANALYSIS_INCOMPLETE`**——`ONE_FINAL_QWEN_EXPERIMENT_REQUIRED` 作为 05 的结论**撤回**。

撤回理由（均来自 07 的核验）：
1. 05 把 CA-MER 16 类测量描述为"已规划但无输出的臂"。运行器只保存生成标签，**不保存候选评分**；所以即使归档里有 A_ONLY/V_ONLY，16 类 entropy/margin/source-prob 也无法在 CPU 恢复，必须**新建一个 16 类教师强制打分测量并重新冻结**，规模与性质都比 05 所述大。
2. 05 的依据"7 类内子集 AUROC 0.64/0.71 vs 0.49/0.52"被验证为：对标签对构成稳健（分层差 +0.287 [0.179, 0.378]），但同时捆绑标签身份、B3 可读性、构造混合与覆盖率（07 A3），且该划分只在随机 7 标签划分的 96.8 分位——特异性弱。它不能当作"测量空间不兼容"的证据。
3. 归档 `audit/QWEN25_CAMER_CONTROLLED_V1` 在本机不可访问，Step B 无法完成，因此有一项**本可由 CPU 完成的分析（A_ONLY/V_ONLY 解析标签的可读性及其与联合选择的关系）仍未完成**。
4. 在上述条件下，CA-MER 16 类测量不是识别价值最高的 Qwen 实验（见下排序）。

CPU 分析还差什么才算完成（唯一阻塞项）：**由有归档访问权的人运行只读 Step 0 审计**（脚本 `analyses/four_regime_synthesis_v1/step0_camer_archive_audit.py`，只读，输出 JSON；本轮在合成夹具上测试过逻辑，未在真实归档上运行）。

## 明确建议：是否应运行 CA-MER 16 类测量
**否，现在不应运行，也不应作为下一个 Qwen 实验。**
- 识别价值：它是观察性的——只能报告熵不对称—选择的关联是否在 CA-MER 复现，不能识别因果或中介，也无法验证伪标签的效度；而且一旦结果为零，无法区分"关联不推广"与"伪标签/提示格式差异"。
- 成本与前置条件：需要新的测量协议与冻结、候选序位置控制（+8.8 pp 效应）、归档核对；而第二模型研究本来就要在 CA-MER 上做同类测量，可在统一协议下一次完成 Qwen 与第二模型，避免为 Qwen 单独冻结一个只服务单数据集的新测量。
- 重新考虑的条件：Step 0 显示归档里已有 16 类逐候选分数（可能性很低，运行器不保存），或第二模型研究确定需要 Qwen 的同协议参照（则与第二模型同一次冻结一并做）。

## 候选比较

### A. CA-MER 16 类单模态测量
| 项 | 内容 |
|---|---|
| 科学问题 | 熵不对称→选择的关联，在另一个自然 A–V 冲突数据集上、在同一标签体系内测量时是否成立 |
| 现有证据 | 7 类 B3 特征：AUROC 0.514 / 0.568（audio-/video-aligned）；仅两标签都在 7 类内时 0.64 / 0.71，其外 0.49 / 0.52；对标签对分层稳健，随机 7 标签划分的特异性 p≈0.03；候选序位置效应 +0.088 [0.019, 0.159]；构造间选择差异 P(音频\|二选一) 0.738 vs 0.368 |
| 可排除的替代解释 | "B3 测量空间不能表示这些标签"（若 16 类熵下 7 类外试次也升高）；部分排除"仅靠标签身份/难度"（需配合 A_ONLY 读对） |
| 仍无法排除 | 伪标签效度、提示格式（JSON vs ET）、数据集特异性、因果/中介、位置效应的混杂 |
| 需要的新数据 | 3000 次 16 类候选打分前向（1500×2）；**新测量协议 + 新冻结**；每个样本沿用既有候选序；若要测稳定性还需重编码对照 |
| 预期样本支持 | 联合二选一 1350 试次/约 743 样本；AUROC 区间半宽约 ±0.045（合并），足以区分 0.5 与 ≥0.6；58 个样本（两序都缺的 CUDA_OOM）结局缺失，补跑媒体可能同样失败 |
| 不可识别的机制 | 因果、熵中介、伪标签是否对应真实情感；跨数据集差异归因于哪个因素 |
| 对核心结论的增量 | 对 R1 的**外部效度**有增量；对 ERI1 因果结论无增量 |

### B. EmotionTalk E1 视频反向质量干预（146 条）
| 项 | 内容 |
|---|---|
| 科学问题 | 音频可靠性效应是否模态对称：视频变差时选择是否转向音频 |
| 现有证据 | ERI1：音频降质使 SIDE_A −10.96 pp，SIDE_V +5.8 pp（未达校正显著，S3）；效应集中在 SNR00 下音频读取丢失的条目（post-treatment 分层，ΔSIDE_A −0.269 vs −0.012，仅描述） |
| 可排除的替代解释 | "音频通道特异扰动"（若视频降质产生镜像效应）；"选择只是总倾向视频"（镜像效应存在时被排除） |
| 仍无法排除 | 熵中介；降质操作本身的特异性（不同降质类型）；模型特异性 |
| 需要的新数据 | 新的视频降质协议（需先确定降质强度与 V_ONLY 读取退化曲线）、冻结与绑定；146 条条目、两序、A_ONLY 对照 |
| 预期样本支持 | 总体上限 146 条（panel 内全部 DualReadable AV 冲突条目；无法扩大）；以音频效应的标准误约 3.3 pp 估计，对 ≥11 pp 的镜像效应功效约 90%，对 6 pp 只有约 40% |
| 不可识别的机制 | 熵中介；是"可靠性加权"还是"退化模态的证据丢失" |
| 对核心结论的增量 | 对"可靠性影响仲裁"的**机制泛化**有增量；若无镜像则收窄为音频特异 |

### C. EmotionTalk 225 个一致样本的音频退化控制
| 项 | 内容 |
|---|---|
| 科学问题 | ERI1 里音频退化后的 SIDE_A 下降，有多少是"一般性扰动"，有多少是"仲裁转向视频"？ |
| 现有证据 | ERI1：SIDE_A −10.96 pp，其中 SIDE_V +5.8 pp（置信区间含 0 的边缘），OTHER +5.1 pp（95% 区间 [+1.7, +9.0]）——**净下降约一半没有变成视频选择**。一致样本在干净条件下共享标签保持率 448/450（99.6%），有充足下探空间 |
| 可排除的替代解释 | "音频退化一般性破坏输出"（若一致样本在同样噪声下共享标签保持率不降，或 OTHER 增量远小于冲突样本）；也能量化 ERI1 里"非仲裁"部分的上限 |
| 仍无法排除 | 熵中介；视频对称性（B）；一致样本里模型可能直接依靠视频，所以"保持"不等于"音频无扰动" |
| 需要的新数据 | 新条目的音频降质绑定（ERI1 绑定仅覆盖 146 条）；噪声管线与 ERI1 完全相同；条件 RECODE + 至少 SNR00（建议含 SNR10/20 作剂量）；两序；A_ONLY 读取 |
| 预期样本支持 | 225 条/177 个对话簇（127 ALL_SAME + 98 A=V≠T；共享标签 neutral 115、happy 59、sad 25、angry 23、surprised 3）；ERI1 的 ΔOTHER 标准误约 0.019（146 条），225 条约 0.015，对 +0.05 的 OTHER 增量功效约 90%。**注意 51% 是 neutral**，需要按标签报告 |
| 不可识别的机制 | 熵中介；一致样本里没有 SIDE_A / SIDE_V 之分，无法直接复现主要终点 |
| 对核心结论的增量 | 对 ERI1 的**解释**有增量（把 SIDE_A 下降拆成扰动与仲裁），不改变已封版的主要结论；成本最低 |

### D. 不增加 Qwen GPU，直接进入第二模型
| 项 | 内容 |
|---|---|
| 科学问题 | 主要关联与因果结论是否跨模型成立 |
| 现有证据 | Qwen 单模型：R1（ET 内 CV AUROC ≈0.80）、ERI1（H1 p=0.0017） |
| 可排除的替代解释 | "Qwen 特异"；但**无法**排除 ERI1 内部的"一般性扰动"解释（因为那需要一致样本控制，Qwen 与第二模型都没有） |
| 需要的新数据 | 第二模型的完整新测量；若同时纳入 B/C 的对称设计，则 Qwen 缺少同设计参照 |
| 预期样本支持 | 与 Qwen 已有总体同尺度 |
| 不可识别的机制 | 模型间差异的来源（架构、训练、提示接口）；第二模型若出现与 Qwen 不同的 B/C 结果，无法判定是模型差异还是 Qwen 缺对照 |
| 对核心结论的增量 | 外部效度（跨模型）增量最大，但**不增加 Qwen 内部识别** |

## 排序（仅按识别价值）
1. **C**——用最低成本直接拆分已封版主效应的两个来源（扰动 vs 仲裁），总体已存在且基线有空间，功效可估；缺点是不改变主要结论、只改进解释。
2. **B**——识别"模态对称"这一关键机制性质，但总体不可扩大，功效对小效应不足，并需要新降质协议。
3. **A**——观察性、外部效度、需新测量协议与冻结、归档未核实、伪标签效度未知。
4. **D**——外部效度最大，但不提供 Qwen 内部识别；作为"不再增加 Qwen GPU"的默认选项成立，条件是接受 ERI1 的解释范围保持为 05 之前的限定表述。

## 按分支的结论（不替用户决定）
| 情形 | 建议 |
|---|---|
| 目标只是保持论文已封版的限定性主张（ERI1 = "音频加噪改变该模型在该总体上的仲裁选择"） | 可选 D：Qwen 不再增加 GPU，第二模型研究把 B 与 C 的对称设计写入其预注册，并在论文里明确 Qwen 缺这两个对照 |
| 目标是把 ERI1 升级为"仲裁/可靠性加权"机制主张 | 先 C，再视结果决定 B；两者都应在运行前单独预注册，且不依赖 CA-MER |
| 想补 R1 的跨数据集外部效度 | 与第二模型研究合并做统一的 16 类 CA-MER 测量，不单独为 Qwen 冻结 |

**本报告不选择上述任一分支**；这是研究目标层面的决定。无论哪个分支，当前都不批准 GPU。
